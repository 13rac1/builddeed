How it works

  1. Buy a license. One wallet approval. The license is an NFT in your account.
  2. Register your computer. The program opens this site; the license has seats for your computers.
  3. Resell it when you are done. List it on Used licenses; the developers get a royalty.

Verified builds. Each official file is built from public source, attested by GitHub, and its SHA-256 is recorded on chain. Verify a download

Questions

Is this DRM?

No. The license check is in public source code, and anyone may build the program without it. What a license sells is the official build, its updates, and a license you can sell later. Shareware worked the same way: most people paid because it was easy and fair.

What happens when I sell my license?

List it on Used licenses at your price (at least the renewal price). When it sells, 3% goes to BuildDeed, the product's royalty goes to the developers and contributors, and the rest goes to you. The sale removes your computers from the license, so your copies go back to unregistered. A wallet transfer is refused, so that the royalty is paid.

How many computers can I use?

Each product sets the number of seats; its page shows it. You add a computer from the program ("I have a license"), and remove one on My licenses to free its seat.

Does the program work offline?

It runs, but unregistered. The program asks the contract for its seat at each start. It keeps no license result on the computer, because a stored result could be copied or edited.

What does "updates for 365 days" mean?

A license covers each official build released in that time after you buy it, and you keep those builds after that. Renew to extend the period.

What is a verified build?

The developer's release builds each file in a pinned container from the public source, GitHub attests the build, and the contract records the file's SHA-256. A recorded file cannot be changed. Drop a download on Verify a download to check it.

Is this real money?

Not yet. This demo runs on NEAR testnet, and testnet NEAR has no value. Get some free from the faucet and try everything.
